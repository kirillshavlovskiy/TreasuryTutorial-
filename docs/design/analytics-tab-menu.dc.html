Turn 1 · Analytics module tab menu
Today the row is four detached pills followed by two competing H-level headings and two description lines, so the tab looks like a filter chip and the module title repeats. Four treatments on the existing slate/sky kit: 1d shadcn TabsList · 1a underline rail · 1b segmented control · 1c rail with per-tab figures. Click a tab in any frame.
1d shadcn TabsList · muted track, raised active trigger
Callouts · 1d
  • TabsList — inline-flex h-9 items-center rounded-lg bg-muted p-1 text-muted-foreground. Here bg-muted maps to bg-slate-800/60 so the track sits above the panel without a border. shadcn's list has no outline; the fill alone separates it.
  • TabsTrigger active — rounded-md bg-background text-foreground shadow-sm: the active tab is a raised surface, not a coloured one. bg-slate-950 against the muted track plus a 1px hairline reads as the panel showing through, which is why it needs no accent at all.
  • Inactive triggers — plain text-slate-400, no fill, no border; hover only lifts the text. Disabled is opacity-50 pointer-events-none, which is what the Soon tabs use.
  • Sizing is fixed, not padded ad hoc — h-9 list, px-3 py-1 text-sm font-medium triggers, gap-0. That standard metric is most of why the pattern reads as a system component rather than four buttons.
  • Focus ring is part of the spec — focus-visible:ring-2 ring-sky-500 ring-offset-2 ring-offset-slate-900. Keyboard nav is arrow keys within the list, one tab stop for the whole group.
  • Where the accent goes — nowhere on the tab. Sky stays on values and the Tf chip, so the tab row is the quietest thing in the header, which is the shadcn default and the right call here.

1a Underline rail · tabs sit on the panel edge
Callouts · 1a
  • Tabs sit on a rail, not in boxes — border-b border-slate-700 across the full panel width, active tab border-b-2 border-sky-500 text-slate-50. A bordered pill is the same component the desk uses for filters and toggles elsewhere; a rail can only mean navigation.
  • One heading, not two — the module H2 and the per-tab H2 collapse into a single title that names the active tab (Analytics — Cash Carry) with one description under it. Today both headings are the same size and weight, so neither wins.
  • Description belongs to the tab — it moves below the rail and swaps with the tab, which is what makes the second heading redundant in the first place.
  • Disabled tabs stay in place — text-slate-600 cursor-not-allowed with a Soon chip in text-[9px] uppercase tracking-[0.09em]. No border, no hover, so they read as roadmap rather than as something that failed to load.
  • Context row is right-aligned on the rail — Tf and the gear move up onto the tab line. That removes the third stacked meta line entirely.

1b Segmented control · one enclosure, sliding fill
Callouts · 1b
  • One enclosure, not four — rounded-lg border border-slate-700 bg-slate-950/60 p-1 with the active segment as a filled rounded-md bg-slate-800 text-slate-50. Four separate bordered pills read as four independent toggles that could each be on; a single track reads as one choice.
  • Active fill is slate, not blue — the current blue pill is the loudest element on a screen where blue also marks editable values and live figures. Selection is conveyed by the fill, and a 2px sky underline inside the segment carries the accent at a fraction of the weight.
  • Sits beside the title — the control is short enough to share the header line, which removes a whole row of vertical space and puts the module name and its section in one glance.
  • Soon segments are inside the track — text-slate-600, no fill, Soon in text-[9px]. Keeping them inside the enclosure shows the full roadmap without implying four live options.
  • Best when tabs stay ≤ 4 — a segmented control does not survive growth. If DV01 and Greeks ship and a fifth arrives, 1a is the treatment that scales.

1c Rail with per-tab status · densest
Callouts · 1c
  • Each tab carries its headline figure — a mono value under the label, so the desk sees where the exposure is before it clicks. On a treasury screen a tab that shows nothing until selected wastes the row.
  • Rail on top, not bottom — border-t-2 border-sky-500 on the active tab, with the whole tab block sitting flush in the panel head. It reads as a card selector, which suits tabs that carry data.
  • Values are muted on inactive tabs — text-slate-500 against text-slate-100 on the active one. The figures are context, not four competing readouts.
  • Cost — it needs a real number per tab. DV01 and Greeks show an em dash until they ship, which is honest but leaves two thirds of the row empty at launch.
